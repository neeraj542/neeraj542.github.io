Exploring Basic C++ Programming with calC

Today, I want to share a little project I’ve been working on called calC. It’s a simple calculator app built in C++. If you’re starting with programming or want to improve your C++ skills, this project is a perfect hands-on exercise.

Live Link:

https://neeraj542.github.io/BuildingCPP/

What is calC?

calC is a basic calculator that lets you perform four essential arithmetic operations:

  1. Addition (+)

  2. Subtraction (-)

  3. Multiplication (*)

  4. Division (/)

Why Did I Create calC?

As a developer, I find revisiting the basics always good. Creating a simple calculator like calC helps reinforce fundamental concepts such as user input, functions, and control structures in C++. Plus, it’s a fun way to build something useful!

How Does calC Work?

Here’s a quick rundown of how calC operates:

  1. User Input:

    • You start by entering two numbers.

    • Then, you choose an operation by entering a number (1 for addition, 2 for subtraction, etc.).

  2. Performing Operations:

    • The app uses a function named calC to perform the selected operation.

    • A switch-case statement inside the function determines the correct operation and returns the result.

  3. Displaying Results:

    • Finally, the app displays the result of the calculation.

Here’s a snippet of the core function:

auto calC(int a, int b, int op) {
    switch (op) {
        case 1: return (a + b);
        case 2: return (a - b);
        case 3: return (a * b);
        case 4: return (a / b);
        default: return -1;
    }
}

Why You Should Try It

Creating something like calC is a great way to practice:

  • User Input: Learn how to handle input from users.

  • Functions: Understand how to use and return values from functions.

  • Control Structures: Get comfortable with switch-case statements.

Give It a Go!

If you're learning C++ or just want to create something straightforward, try building your own version of calC. You’ll gain confidence in your coding skills and have a handy calculator to show off!
